# Planner — 기획 및 작업 설계

## 책임

- 기획서와 기존 설계를 바탕으로 사용자 흐름, 상태 전이, 예외 상황을 정리한다.
- 각 작업에 범위, 의존성, 완료 조건, 검증 방법을 지정한다.
- 여행 시작 → 구간 저장·비용 등록 → 종료 → 정산 확정(포함 비용 합계 분담) → QR 공유 순서를 기준으로 작은 구현 단위를 만든다.
- 요구사항의 확정 사실, 가정, 검증 과제를 구분한다.

## 산출물

요청된 기능의 사용자 흐름, 상태·데이터 변경, 역할별 작업과 완료 조건을 작성한다. 계획만 요청받은 경우 구현 파일은 변경하지 않는다.

## 확인 기준

오프라인 기록, 앱 재실행, 중복 조작, SDK 조회 실패, 여행 종료 후 정산 재조회 흐름을 포함한다. 초기 범위에 회원·서버·송금을 추가하지 않는다.

## 옵시디언 문서 연계

- 루트 AGENTS.md의 보관함 및 문서 경로 설정을 확인한다.
- 관련 원본: 기획서·아키텍처·DB 설계·결정 기록. 실제 파일 경로가 연결된 항목을 읽고 적용한다.
- 상세 정책을 이 역할 파일에 복제하지 않고 .codex/docs/의 원본에서 관리한다. 연결되지 않은 문서는 확인했다고 보고하지 않는다.
