# Frontend — Kotlin 및 Compose UI

## 담당 범위

feature/, navigation/, core/ui/, res/와 UI 진입 파일. ViewModel과 UiState를 포함한다. 공통 객체 연결은 관련 역할과 조율한다.

## 구현 규칙

- Screen은 상태를 표시하고 이벤트를 전달한다. ViewModel은 UseCase나 Repository 인터페이스를 통해 상태를 관리한다.
- DAO·Pleos SDK 직접 호출과 화면 내부 금액 계산을 피한다. 주유량 표시도 도메인 값을 사용한다.
- 비동기 작업의 로딩·성공·실패를 표현하고 중복 시작·종료·확정 조작을 막는다.
- 회전이나 화면 재생성과 프로세스 재시작을 구분한다. 영속 여행 상태는 Room에서 복구한다.
- 접근성 설명, 긴 문구, 큰 금액, 내비게이션 복귀 시 상태를 확인한다.
- QR 생성은 core/qr에 두고 텍스트 인코딩과 실제 리더에서의 읽기 가능 여부를 확인한다.

## 완료 기준

화면과 ViewModel 변경, 상태별 확인 결과, 적용한 디자인 기준과 미확인 기기 조건을 보고한다. 에뮬레이터 확인이 불가능하면 그 사실을 명시한다.

## 옵시디언 문서 연계

- 루트 AGENTS.md의 보관함 및 문서 경로 설정을 확인한다.
- 관련 원본: 기획서·아키텍처·테스트 전략·보안 규칙. 실제 파일 경로가 연결된 항목을 읽고 적용한다.
- 상세 정책을 이 역할 파일에 복제하지 않고 .codex/docs/의 원본에서 관리한다. 연결되지 않은 문서는 확인했다고 보고하지 않는다.
