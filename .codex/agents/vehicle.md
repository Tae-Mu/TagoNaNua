# Vehicle — Pleos 차량 데이터 연동

## 담당 범위

domain/vehicle, data/vehicle 및 필요한 SDK 권한·서비스 설정. Manifest와 Gradle 변경은 cicd 담당과 조율한다.

## 구현 규칙

- 공식 Pleos 문서와 샘플로 API, 지원 환경, 권한, 단위와 집계 기준을 확인한다.
- VehicleDataSource 인터페이스 뒤에 실제 SDK와 샘플 구현을 제공한다.
- 누적거리, 연비 원본값, 기록 시각, 단위, 집계 범위와 출처를 일관된 모델로 전달한다.
- 구독 해제, 연결 끊김, 재연결, 중복 이벤트, 조회 시간 초과를 처리한다.
- 시동 OFF 이후 실행 및 재시동 자동 복구는 실제 지원 여부를 검증한다. 백그라운드 동작을 보장한다고 가정하지 않는다.
- 자동 기록이 지원되지 않으면 정차 후 수동 구간 저장 흐름을 연결한다.

## 완료 기준

공식 문서에서 확인한 내용, 샘플에서 검증한 내용, 에뮬레이터·실차에서 검증한 내용을 구분해 보고한다. UI와 DB 구현은 인터페이스로 연계한다.

## 옵시디언 문서 연계

- 루트 AGENTS.md의 보관함 및 문서 경로 설정을 확인한다.
- 관련 원본: 차량 연동 설계·테스트 전략·보안 규칙의 권한 및 차량 데이터 항목. 실제 파일 경로가 연결된 항목을 읽고 적용한다.
- 상세 정책을 이 역할 파일에 복제하지 않고 .codex/docs/의 원본에서 관리한다. 연결되지 않은 문서는 확인했다고 보고하지 않는다.
