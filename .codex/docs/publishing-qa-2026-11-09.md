## 남은 차이와 범위

- 아직 HTML과 모든 픽셀이 일치한 것은 아니다. CSS blur, 글자별/하위 요소별 모든 모션, 일자 선택 UI는 차이가 남는다.
- 시스템 상태 표시줄·Android 태블릿 작업표시줄·키보드는 웹 시안에 없는 네이티브 영역이다.
- 금액·기록·목록은 고정 샘플. 실제 계산, 저장, 차량 복원, 비용 CRUD는 이번 작업 범위에 포함하지 않는다. 화면에서 실제 영속 저장처럼 보이는 문구는 시안 안내로 구분한다.
- 작은 분할창, 큰 글꼴, TalkBack, 실차 화면은 이번 가로 태블릿 검수 완료로 간주하지 않는다.

## 최종 재검수 결과

- 최종 APK: `:app:assembleDebug :app:lintDebug` 성공. Lint 오류 0개, 경고 8개(의존성/타깃 버전, Compose API 관례, 방향 고정/백업 설정). 경고 해결을 완료한 것으로 간주하지 않는다.
- 최종 APK 설치 후 앱을 새로 실행해 16개 화면/전환 확인 항목 통과. 여행 이름 입력 → 출발 안내 → 기록 → 주차비 입력 → 등록 후 기록 복귀 → 종료 확인 → 완료 → 홈, 여행 내역 상태 필터, 월 선택 적용을 실제 ADB 조작으로 확인.
- 월 선택 검증은 선택 월 표기 변경이며 월별 실제 데이터 조회 검증이 아니다. 비용 등록도 화면 복귀 검증이며 데이터 저장 검증이 아니다.
- 출발 0.6/1.6/3.5/4.4초 캡처를 보관해 안내 화면과 기록 화면의 중첩 전환을 확인했다.
- 재설치 직후 기존 내역 화면에서 시작한 테스트는 홈 버튼을 찾지 못했다. 시작 상태를 앱 재실행으로 맞춘 뒤 전체 시나리오를 재실행해 통과했다. 이전 `failure.png`는 이 테스트 준비 실패 기록이며 최종 결과는 `qa-results.json`을 따른다.
- 비용 페이지 최종 캡처에서 주차비 제목, 여행 이름, 선택 입력 예시와 안내를 확인했다. 하단 등록 버튼은 스크롤로 접근하며 실제 등록 후 기록 복귀도 재확인했다.
