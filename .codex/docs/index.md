## 관리 방식

문서 내용은 구현 완료를 뜻하지 않습니다. 확정된 요구사항과 검증이 필요한 가정을 구분합니다. 정책 변경 시 관련 문서와 결정 기록을 함께 갱신합니다. 구현 상태와 실행 방법은 저장소 루트 README.md에서 관리합니다.
