# 보안 10대 규칙

같이타 프로젝트 내부 작업 기준입니다. 특정 보안 인증이나 외부 표준의 준수 선언은 아닙니다.

1. **비밀정보 제외**: 인증정보, 서명 키, local.properties를 저장소·로그·문서에 넣지 않습니다.
2. **최소 차량 권한**: 실제 기능에 필요한 SDK 권한만 선언하고 지원 여부를 확인합니다.
3. **입력 검증**: 사용자 및 차량 입력의 범위·단위·집계 기준을 확인합니다.
4. **안전한 쿼리**: DAO에서 매개변수 바인딩을 사용하고 외부 입력으로 SQL을 조합하지 않습니다.
5. **내부 저장소**: Room DB는 앱 내부 저장소에 두고 외부 공개 경로에 복제하지 않습니다.
6. **민감 로그 금지**: 참여자 이름, 여행 상세와 인증정보를 운영 로그에 남기지 않습니다.
7. **최소 QR 정보**: 정산에 필요한 값만 담고 차량 식별자나 전체 여행 기록을 포함하지 않습니다. 텍스트 QR은 암호화나 접근 제어가 아닙니다.
8. **컴포넌트 노출 제한**: Activity·Service·Receiver의 외부 노출을 검토하고 필요한 진입점만 허용합니다.
9. **백업·내보내기·삭제 명시**: 포함 데이터와 보존 범위를 설계하고 앱 데이터 삭제 시 기록 삭제를 안내합니다.
10. **의존성 및 릴리스 검토**: 의존성 출처·알려진 취약점·호환성을 확인하고 릴리스의 디버깅을 비활성화합니다.

## 검증 책임

backend는 입력·DAO·저장을, frontend는 공유 정보·오류 표시를, vehicle은 권한·차량 데이터를, cicd는 비밀정보 노출·의존성·릴리스 설정을 확인합니다. 자동 검사와 수동 검토를 구분하며 검사 도구가 없는데 검사가 통과했다고 보고하지 않습니다.
