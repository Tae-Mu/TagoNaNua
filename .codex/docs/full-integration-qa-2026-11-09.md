# TAGO 전체 기능 연결·QA 기록 — 2026-11-09

## 범위

`loren_dev`의 실제 앱(`com.gatita`)에 연결했다. 별도 HTML/PublishingApp 샘플의 고정 데이터를 실제 앱에 연결하지 않았다. 화면 → ViewModel → UseCase → Repository → Room 구조다. 네트워크 서버·로그인·송금은 기존 제품 범위에 없다.

| 화면·동작 | 연결 내용 |
|---|---|
| 홈·출발 준비 | 이름, 인원 1~8, 운전자 포함, 수동 시작 주행거리, 시작 로고 전환, 활성 여행 복구 |
| 여행 기록 | Room 구간·거리·구간 경과 시간, 수동 구간 입력, 비용 요약, 여행 완료·빈 여행 닫기 |
| 잠시 멈춤 | 수동 일시정지 저장, 재실행 후 같은 여행 복구/재개, 정지 중 구간 입력 차단 |
| 비용 | 주유·주차·톨비·기타 추가/수정/삭제, 선택 내용, 주유 금액·리터당 단가 필수, 날짜 UI, 표시용 주유량 |
| 비용 내역 | 종류별 소계, 정산 포함/제외, 등록·포함·제외 합계. 기록 화면에서 추가하면 등록 후 기록으로 복귀 |
| 여행 완료 | 저장된 실제 비용·구간 안내, 바로 정산 또는 나중에 정산 |
| 정산 | 포함 비용 합계, 인원/운전자 정책 저장, 표시 이름, 정수 원 분담, 나머지 배분, revision 기반 확정 |
| 결과·공유 | 저장된 불변 스냅샷, 요약 복사, UTF-8 QR, QR 최대 320dp, legacy 읽기 구분 |
| 내역·정산 목록 | 월 선택, 상태 필터, 실제 통계·상세, 완료 여행 목록 삭제와 확인/취소 |
| 설정 | 이름·운전자 기본값·화면 모드 영구 저장, 설정 초기화, 저장·로딩 오류 처리 |

목록 삭제는 `trip_sessions.hidden=1`로 목록/통계에서 제외하는 기능이다. 확정·legacy 원본은 보관하며 확인창에서 이를 알린다. 영구 삭제라고 표현하지 않는다. 진행 중 여행은 목록 삭제 대상이 아니며 빈 여행은 기존 ‘닫기’로 폐기할 수 있다.

## 이번 검수에서 수정한 문제

- 이전 테스트가 추정 유류비 화면의 제거된 API를 참조하여 컴파일되지 않음 → 현재 결제액 ViewModel/화면에 맞춰 갱신, legacy 계산 테스트 유지.
- 구간 저장 후 증가한 revision을 무시하던 오래된 복구 테스트 → 실제 갱신 규칙 검증으로 변경.
- 설정이 메모리에서만 적용됨 → Room v3 저장/초기화, 새 여행과 정산 이름 기본값 연결.
- 일시정지 UI에 영속 상태 없음 → Room v4 세션 저장과 상태 전이 연결.
- 비용 수정에 expectedRevision 미전달 → 오래된 편집 차단, 입력 보존, 최신 내용 재조회 버튼.
- 비용 저장 성공 후 이동 전 재탭 시 새 requestId로 추가 저장 가능 → 성공한 폼의 후속 저장 차단, 회귀 테스트 추가.
- 설정 읽기 실패 후 초기값으로 덮어쓸 수 있음 → 오류 상태와 재시도, 읽기 실패 중 저장 차단.
- 야간 모드에서 시스템 상태 표시줄 아이콘 대비 불일치 → 저장된 모드에 맞게 시스템 아이콘 색상 동기화.
- 여행 기록 요약의 좌우 카드 높이 차이 → 같은 높이로 정렬.
- 이전 연결 검수에서 QR 과대 확장과 사이드바의 잘못된 중첩 화면 복원도 수정했다.

## 테스트 데이터 주의

Room 테스트 코드는 별도 이름의 테스트 DB만 생성·삭제한다. 다만 Gradle UTP의 로그에서 대상 APK `uninstall_after_test: true`를 확인했고, 이전 QA 샘플이 사라진 점을 발견했다. 이 에뮬레이터에서 이전 QA 기록이 유지됐다고 주장하지 않는다. 이후에는 `adb install -r` 후 `am instrument -w`로 실행하여 테스트 종료 시 대상 앱을 제거하지 않도록 전환했다. 현재 직접 QA 여행은 의도적으로 목록 삭제한 상태이며 원본은 남는다. 기기 테스트는 운영 사용자 데이터가 있는 기기에서 실행하지 않는다.

## 외부 의존성과 검증 한계

- 실제 Pleos SDK 구현/차량 환경이 없다. 시동 OFF 자동 저장, PARKED 신호에 따른 편집 차단, 실제 거리·연비 수집은 **미연결**이다. 수동 입력과 수동 pause를 실제 차량 자동 동작으로 표시하지 않는다.
- 하이패스·카드 자동 결제 수집, 실제 송금/입금 확인은 범위 밖이다. 주차/톨비는 직접 입력한다.
- 범용 command_receipts 테이블은 추가하지 않았다. 비용 등록과 확정은 기존 requestId, 수정을 위한 revision과 UI 중복 제출 방어를 사용한다.
- 실제 휴대폰 카메라 QR 리더, 실차, 다른 Android 버전·모든 화면 배율의 검증은 수행하지 않았다. QR 인코딩 단위 테스트와 태블릿 렌더링은 통과했다.
- HTML의 모든 픽셀/모션 일치를 보증하는 검수가 아니라 실제 앱 기능 연결과 상태/데이터 검증이다.

코드·문서 변경은 작업 트리에 있으며 이번 요청에서 커밋/푸시는 수행하지 않았다.
