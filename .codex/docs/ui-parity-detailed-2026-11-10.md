# HTML ↔ Compose 상세 대조 (2026-11-10)

## 비교 조건
- 기준: `HD 프로젝트/preview`의 현재 HTML/CSS와 localhost 화면.
- 태블릿: TAGO_Tablet, 2560×1600 px / density 320. 앱 콘텐츠 1280×716 dp와 HTML 1280×716 CSS px를 비교.
- 실데이터 화면은 기존 여행을 수정하지 않고 탐색. 기록·완료·확정 결과는 실제 운영 Composable에 격리된 fixture를 전달해 캡처.
- 이번 변경은 로컬 변경이며 커밋/푸시하지 않음.

## 발견한 차이와 반영
| 화면/요소 | 기존 차이 | 반영 |
|---|---|---|
| 진행 중 여행 진입 | HTML에 없는 제목/설명/이어가기/내역 카드 | 실제 진행·정차 화면으로 바로 진입. 완료 상태도 유지 |

| 홈 | 전체 정산 버튼이 주 동작처럼 큼 | 14sp/48dp, 좁은 패딩과 아이콘 간격 |

| 설정 | 프로필 로고/타이틀/패딩 상이 | 이름 이니셜, 섹션 타이포와 28dp 패딩 |
| 전역 | 진행 중 여행 배너와 뒤로가기 위치 상이 | 실제 active 여행 기반 배너, 제목 위 뒤로가기 |

## 데이터와 동작의 의도적 차이
- HTML의 차량·거리·장소는 샘플. 앱은 SDK 값이 없으면 연결 대기/미기록을 표시한다. 거리 수동 입력과 가짜 정차 상태를 추가하지 않는다.
- 구간의 실제 계기판 시작/끝 값은 장소 이름으로 위조하지 않는다.
- 확정 금액은 저장된 분담 결과를 표시하며 다시 계산하지 않는다.
- 실제 앱의 삭제 확인, 오류, 연결 대기, 레거시 읽기 전용 구분은 유지한다.

## 아직 HTML과 같다고 단정하지 않는 부분
- 정산 미리보기의 개별 비용 편집은 비용 내역 화면으로 이동한다. HTML의 정산 페이지 내부 비용 행과 구조가 동일하지 않다.
- 정산 미리보기 제목은 현재 ViewModel 계약상 일반 제목이며 여행명 헤더와 차이가 있다.
- SDK 미연결 상태의 출발 모션과 실차 기록 전체 흐름은 실차 검증이 필요하다.
- 기기 폰트 배율·다른 화면 크기·다크 모드의 전 화면 픽셀 일치는 이번 검증 범위가 아니다.

## 후속: 화면 전환 끊김 수정

- 원인: NavHost의 enter/exit 전환이 `None`이어서 이전 화면이 즉시 제거되고, 새 Scaffold만 100ms 밝아졌다. 상위 배너도 현재 route에 따라 즉시 바뀌어 퇴장 화면의 높이가 변했다.
- 변경: NavHost가 이전/다음 화면을 180ms 교차 페이드한다. 화면별 중복 페이드를 제거하고 배너 표시 여부를 각 destination에 고정했다. 상하 슬라이드나 높이 애니메이션은 추가하지 않는다.
- 메뉴 재방문은 saveState/restoreState로 스크롤·필터·ViewModel 상태를 복원하고, 동일 메뉴 재선택은 무시한다. 완료 후 홈 진입은 완료 화면이 남지 않도록 새 홈으로 연다.
- 홈/정산 목록은 이미 Room을 관찰하는 공통 HomeViewModel을 사용해 동일 데이터의 불필요한 재로딩을 줄인다.
- 검증: 이번 변경 후 assembleDebug 및 lintDebug 성공. 기존 테스트 수치를 이번 변경의 결과로 재사용하지 않는다. 태블릿 메뉴 왕복과 영상 확인은 아래에 기록한다.

- 실제 메뉴 검수: 여행 → 여행 내역 → 설정 → 정산 → 여행 내역 → 여행 및 동일 여행 메뉴 재선택 통과. 기존 여행 데이터 유지 확인.
- 에뮬레이터가 `-gpu swiftshader` 및 GPU 비활성 설정이었다. TAGO_Tablet만 종료 후 `-gpu host`로 재시작했고, 다음 실행도 GPU 가속을 사용하도록 AVD 설정을 변경했다.
- 녹화 동반 메뉴 왕복 측정: 소프트웨어 렌더링 72프레임 중 jank 71(98.61%), 중앙 프레임 시간450ms → GPU 가속315프레임 중 jank8(2.54%), 중앙17ms. 동일 프레임 수의 통제 벤치마크는 아니며 실기기 성능 보장은 아니다.
- 영상·계측: `app/build/visual-review/navigation-motion/navigation-host.mp4`, `gfxinfo-host.txt`.

## 후속: 여행 내역 월 선택 디자인

- 여행한 달 버튼: 달력과 선형 펼침 아이콘, 20sp SUIT, 56dp 높이, 14dp 모서리. 문자 화살표 제거.
