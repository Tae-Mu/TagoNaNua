# Pleos 화면 비율·입력 동작 검수 — 2026-11-10

## 대상과 기준

- `Pleos_Connect_2_1_0`, Android 14, 사용자 10에서 TAGO 디버그 APK를 직접 설치하고 확인했다.
- 전체 화면 2560×1440, TAGO 앱 영역 (853,90)–(2535,1300), 밀도 160dpi.
- 차량 시스템 영역을 제외한 1682×1210 영역이 기준이다. 전체 디스플레이 폭으로 앱을 늘리지 않는다.
- 기존 HTML의 네이비/블루, SUIT, 좌측 탐색, 카드와 주요 버튼 구조를 유지한다.

## 확인한 문제와 반영

| 문제 | 변경 |
|---|---|
| 160dpi 차량 화면에서 일반 태블릿 크기의 글자·버튼이 작음 | VehicleViewport에서 앱 폭을 기준으로 1–1.5배 적용. 현재 Pleos는 약 1.402배로 1200dp 작업 폭. 폰트 배율 설정은 보존 |
| 본문 대비 좌측 탐색과 바깥 여백 비중이 큼 | 탐색 폭 104dp, 본문 여백 28dp, 보조 문구 15sp/22sp 행간 |
| 탐색 버튼에 누름 반응이 부족함 | 공통 pressMotion 적용, 아이콘과 텍스트 터치 영역 유지 |
| 필터 항목이 가로로만 배치됨 | ChoiceChips를 FlowRow로 전환 |
| 별도 Dialog가 Android 기본 밀도로 돌아가 작아짐 | VehicleDialog가 호출 화면의 LocalDensity를 내부에 다시 제공. 날짜·여행 완료·출발 모션에 적용 |
| 삭제·정산·설정 확인창의 비율이 따로임 | VehicleAlertDialog로 통일, 내용 스크롤과 최대 폭 적용 |
| 일 선택 달력의 이전/다음 버튼에 문구가 끼어듦 | 의미 설명이 있는 방향 아이콘, 56dp 터치 영역과 52dp 날짜 행, 최대 폭 520dp |
| Room이 먼저 새 여행을 알리면 시작 이벤트 수집기가 사라져 모션을 건너뜀 | HomeRoute 이벤트 수집을 항상 유지하고 시작 대기 상태와 활성 여행 표시를 분리 |
| 출발 모션이 끝난 뒤 다음 화면을 다시 생성함 | 모션 퇴장 시점에 기록 화면을 뒤에서 먼저 구성, 홈의 활성 여행 콘텐츠를 그대로 유지 |
| 비용 종류/출발 준비/비용 목록에서 시스템 뒤로 가기가 화면의 뒤로 가기와 다름 | 화면별 BackHandler로 내부 단계부터 복귀 |
| 비용 종류의 시각적 구분 부족 | 주유·주차·톨비·기타 공통 선 아이콘 적용 |
| 기록이 없다는 이유로 차량이 연결되지 않았다고 표시함 | '구간 기록 대기'와 '여행 시작 시 연결 확인'으로 실제 확인 가능한 범위만 안내 |

## 검증

- `assembleDebug`, `assembleDebugAndroidTest`, `testDebugUnitTest`, `lintDebug` 성공.
- JVM 단위 테스트 125개: 실패/오류/건너뜀 0.
- Pleos UI 계측 테스트 12개 통과 (실패 0): `PleosInteractionTest`, `VisualParityTest`, `ScreensTest`.
- 새 테스트는 비용 네 종류의 입력 진입/복귀, 월 변경의 적용 전 임시 상태와 취소, 6주 달력 마지막 날짜 선택을 검증한다.
- 기존 화면 테스트는 홈→준비, 기록→완료 확인, 완료→정산 버튼, 확정 금액과 공유 화면 등을 검증한다.
- 실제 앱에서 기록 화면, 비용 종류, 주유 상세 펼치기, 날짜 선택, 여행 내역/월 선택, 정산 빈 상태, 설정 진입을 직접 조작했다.
- UI 계측은 격리된 상태를 사용한다. 사용자 여행을 완료/삭제하거나 시험 비용을 저장하지 않았다. APK 교체는 `adb install -r`; 앱 데이터 초기화 없음.

## 검증 한계

- 실제 차량 주행 중 입력, SDK 시동 이벤트에 따른 자동 구간 생성과 기록 지속성은 이번 화면 검수의 통과 항목이 아니다. 빈 기록을 임의 거리로 채우거나 수동 거리 입력을 추가하지 않았다.
- 삭제·정산 확정 등의 파괴적 동작은 사용자 데이터에 직접 실행하지 않았다. 화면 콜백 및 기존 도메인 단위 테스트와 UI fixture를 사용한다.
- 모든 창 크기·실차 기종 검증을 의미하지 않는다. 위 Pleos 에뮬레이터 앱 영역에서 검수했다.
