# Pleos 확인창 화면 개선 — 2026-11-11

사용자 첨부 화면의 여행 완료창·월 선택창을 기준으로 수정했다.

- OEM Window dim에만 의존하지 않고 `VehicleDialog` 내부에서 검정 40% 배경을 직접 그린다. 앱 창 전체를 덮으며, 카드 뒤 버튼이 겹쳐 보이지 않게 한다. 시스템 차량 영역에는 적용하지 않는다.
- Dialog의 Window dim은 0으로 설정해 중복 어두워짐을 방지한다. 날짜 창의 개별 Window dim 코드는 제거했다.
- 배경 터치는 창을 닫고 카드 내부 빈 곳 터치는 창을 닫지 않는다. 기존 선택/확정 콜백을 유지한다.
- 전체 화면 출발 모션에는 별도 어두운 배경을 넣지 않는다.
- 여행 완료창: 최대 폭 500dp, 외부 안전 여백 24dp, 닫기 아이콘, 짧은 설명, 높이가 부족한 경우 내용 스크롤.
- 월 선택창: 연도 이동 버튼을 연한 배경의 공통 버튼으로 변경하고 취소·적용을 52dp로 맞춤. 선택한 달 설명은 14sp.
- 사용자 데이터 삭제·정산 확정 없이 검수한다.

검증: 디버그 앱/테스트 APK 빌드와 lint 통과. PleosInteractionTest 4개 및 VisualParityTest 4개, 총 8개 통과. 플레오스에서 여행 완료창과 월 선택창을 직접 열어 앱 전체 배경 어두워짐과 카드/버튼 배치를 확인했다. 최신 APK를 데이터 유지 방식으로 설치했다.

## 여행 시작 캐릭터 모션

사용자 요청에 따라 여행 시작 안내에 기존 Blender 렌더 `tago_launch.webp`를 재사용했다. 앱 로고는 유지하고 옆에 캐릭터가 이동/페이드로 등장한다. 별도 타이머를 만들지 않고 기존 3.32초 안내 + 0.48초 퇴장 흐름을 유지한다. 비동기 이미지 디코딩 실패가 화면 전환을 막지 않는다. 모션 비활성 설정이면 애니메이션을 시작하지 않으며 창 종료/앱 백그라운드 진입 시 재생을 중지한다. 새 캐릭터나 새로운 Blender 동작을 제작한 것은 아니다.

플레오스 격리 UI에서 여행 이름·안전 문구·바로 기록 보기 및 종료 콜백을 검증하고 실제 렌더 캡처를 확인했다. 빌드와 해당 UI 테스트 통과. 실제 사용자 여행은 추가/완료하지 않았다.

## 빈 여행 닫기 영역

전체 폭 버튼과 별도 큰 제목을 제거하고 구분선 아래에 짧은 안내와 48dp 보조 버튼을 나란히 배치했다. 닫기 아이콘과 15sp 버튼 글자를 사용한다. 기존 노출 조건, 비활성 조건, 확인창 및 삭제 로직은 유지한다. 디버그 빌드 성공 후 플레오스 APK에 적용했다.

빈 여행 삭제 확인창도 여행 완료창과 같은 카드 구조로 정리했다. 여행 이름, 복구 불가 안내, '계속 기록'/'빈 여행 삭제'의 동일 크기 버튼을 제공한다. 삭제 조건과 데이터 처리 코드는 변경하지 않았다. 긴 내부 동작 설명은 제거하고 삭제 오류는 확인창 안에도 표시한다. 빌드 후 플레오스에 적용했다.

## 승인된 B 출발 시안 앱 반영
- 독립 로고·원형 장식을 제거하고 캐릭터 왼쪽 / 여행 이름·안내 오른쪽으로 구성. 좁은 화면은 세로 배치.
- Blender `preview/departure-concepts/source/tago-departure-drift.blend`의 최종 스키드 마크 없는 회전·제동 모션을 사용.
- `tago_departure_spin.webp`: 투명 600×600, 120프레임, 5초, 약 869 KiB. PNG 시퀀스에서 변환. 기존 앱 시작 `tago_launch` 리소스와 분리.
- 하단 점 모션과 바로 기록 보기 버튼. 디코딩 완료 후 5초 재생, 종료 시 기존 기록 화면을 먼저 준비하고 480ms 페이드. 이미지 디코딩 실패 시에도 최대 약 7초 뒤 진행.
- 기존 여행 데이터와 기록 기능은 유지. 뒤로가기·바로 기록 보기로 즉시 전환 가능.
- 검증: debug 앱 및 instrumentation APK 빌드 성공. Pleos 에뮬레이터에서 출발 화면 별도 테스트로 문구·건너뛰기·완료 콜백 검증.

### 출발 화면 여백 조정
- 실제 Pleos 화면 검수 후 콘텐츠 최대 폭을 1080dp로 확장. 캐릭터를 가용 폭의 48%(최대 540dp)로 키우고, 여행 이름 44sp / 안전 안내 32sp로 조정.
- 하단 안내와 버튼을 화면 끝에서 중앙 콘텐츠 그룹 아래로 이동. 가로 간격 16dp, 안내 16sp, 버튼 최소 높이 54dp.
- debug 빌드 및 출발 화면 건너뛰기 instrumentation 테스트 통과. 에뮬레이터 스크린샷으로 캐릭터와 문구의 배치 확인.
