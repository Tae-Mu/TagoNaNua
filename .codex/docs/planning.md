# 같이타 기획

## 목적

친구 여행이나 모임에서 한 차로 이동한 뒤 주행거리와 연비로 예상 유류비를 계산해 분담합니다. 실제 결제나 송금은 초기 범위에 포함하지 않습니다.

## 사용자 흐름

1. 여행 시작: 누적 주행거리와 시각을 저장합니다.
2. 구간 저장: 지원 환경에서는 시동 OFF를 활용하고, 불가능하면 정차 후 수동으로 기록합니다.
3. 여행 종료: 최종 거리와 시각을 저장해 범위를 확정합니다.
4. 정산: 수동 유가와 인원을 입력하고 계산 근거를 확인합니다.
5. 확정 및 공유: 정산을 보존하고 요약 텍스트 QR을 표시합니다.

## 첫 버전

Kotlin·Compose·Room 기반 오프라인 앱입니다. 샘플 데이터로 전체 흐름을 검증한 뒤 실제 Pleos 데이터를 연결합니다. 실제 데이터와 샘플 출처를 구분합니다. 회원, 서버, 클라우드 동기화, 자동 유가 연동은 초기 범위에서 제외합니다.

## 검증 과제

연비 집계 기준, 시동 OFF 후 저장 가능 여부, 재시동 구독 복구, 휴대폰 QR 리더의 텍스트 표시 방식은 검증이 필요합니다.
